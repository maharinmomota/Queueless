# Queueless – Smart Hospital Queue Management System

A web-based Smart Hospital Queue Management System developed as part of the Software Development Project (SDP-I) course.

## Project Overview

Queueless is designed to simplify hospital appointment booking and queue management. It allows patients to explore doctors, view their schedules, book appointments, and manage their queue positions digitally. The system also provides administrative features for managing doctors, schedules, appointments, and patient queues.

## Key Features

- **Doctor Directory:** View available doctors and their information.
- **Doctor Schedules:** Browse doctors' weekly schedules.
- **Patient Registration and Login:** Create an account and securely access the system.
- **Symptom-Based Specialty Suggestions:** Get informational suggestions about relevant medical specialties based on selected symptoms.
- **Appointment Booking:** Select doctors, dates, and available time slots.
- **Digital Queue Management:** Generate queue numbers and manage patient queues.
- **Admin Management:** Manage doctors, schedules, and system users.
- **Queue Assistant:** Manage waiting patients and update consultation status.

## Technologies Used

- **Frontend:** HTML, CSS
- **Backend:** Python, Flask
- **Database:** MySQL
- **Database Connector:** mysql-connector-python
- **Development Environment:** Visual Studio Code, XAMPP

## Project Purpose

The main goal of Queueless is to reduce physical waiting time, improve appointment organization, and provide a more convenient digital queue management experience for patients and hospital staff.

## Disclaimer

This project was developed for academic and educational purposes as part of the SDP-I course. It is a student demonstration project and is not intended for handling real patient data or use in a production hospital environment.
